RIVO CHAT v155 — دمج الواجهة الجديدة مع الدردشة الحقيقية
========================================================

ما تم دمجه:
- واجهة الحاسوب الجديدة في الصفحة الرئيسية.
- تسجيل Google الحقيقي الموجود في مشروع Rivo.
- دخول الضيف والإدارة والمراقب.
- الغرف والرسائل العامة والمتصلون عبر Cloudflare Durable Objects.
- ترتيب المتصلين: الإدارة، المراقبون، VIP، المسجلون، الضيوف.
- شارة التوثيق للمستخدم المسجل، وتاج الإدارة من دون شارة توثيق.
- الاسم المخفي/التاج فقط ووضع الإدارة المخفي.
- الشارة المجانية تبقى أثناء جلسة الموقع والتنقل بين الغرف، وتختفي عند مغادرة الموقع.
- آخر 12 رسالة فقط داخل الغرفة، والواجهة تعرض الرسائل من الأسفل إلى الأعلى.
- الدردشة الخاصة الأساسية والمايك والراديو ولوحة الإدارة الحقيقية.

مهم:
- الكاميرا في الواجهة الجديدة متوقفة مؤقتاً في هذه النسخة حتى لا تتعارض مع البث الحقيقي القديم.
- النسخة القديمة محفوظة احتياطياً على: /legacy.html
- لا تغيّر GOOGLE_CLIENT_ID أو SESSION_SECRET أو ADMIN_TOKEN في Cloudflare؛ تبقى الإعدادات الحالية كما هي.

طريقة الرفع إلى GitHub:
1) فك ضغط هذا الملف في جهازك.
2) افتح مستودع rivo-chat في GitHub.
3) من الصفحة الرئيسية للمستودع اضغط Add file ثم Upload files.
4) اسحب جميع الملفات والمجلدات الموجودة داخل مجلد rivo-chat-v155 إلى صفحة الرفع. لا ترفع ملف ZIP نفسه.
5) اترك Commit directly to the main branch محدداً واضغط Commit changes.
6) انتظر اكتمال نشر Cloudflare، ثم افتح chat.rivolove.com واضغط Ctrl + F5.

ملحوظة أمان:
لا تضع SESSION_SECRET أو ADMIN_TOKEN داخل GitHub. هذه الأسرار تبقى فقط في Cloudflare Variables and Secrets.
