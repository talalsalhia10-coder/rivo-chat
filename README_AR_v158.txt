RivoChat v158 — إصلاح ثبات الجلسة والاتصال والواجهة

التعديلات:
1) يبقى المستخدم داخل الدردشة بعد تحديث الصفحة أو إغلاقها وفتحها مجدداً ما دامت الجلسة صالحة.
2) حفظ الغرفة الحالية وإعادة فتحها تلقائياً.
3) حفظ آخر 12 رسالة في الجهاز واستعادتها عند انقطاع الاتصال أو تحديث الصفحة.
4) عند الانتقال المقصود إلى غرفة أخرى تبدأ الغرفة من جديد كما كان مطلوباً.
5) إضافة نبض اتصال Ping/Pong وإعادة اتصال تلقائية عند انقطاع الإنترنت أو رجوع التبويب.
6) عدم مسح الرسائل الظاهرة أثناء إعادة الاتصال.
7) إظهار: «أنت مسجل بحساب ...» مع زر تغيير حساب Google.
8) زر الخروج يفصل الدردشة لكنه لا يمسح حساب Google المحفوظ؛ يمكن العودة بضغطة واحدة.
9) إزالة عدادات الرسائل التجريبية؛ لا تظهر الفقاعة الحمراء إلا عند وصول رسالة خاصة أو تنبيه حقيقي.
10) ترتيب وتحسين أزرار الرموز واللون والمايك والكاميرا مع منع كود المايك من تخريب الأيقونة.
11) تصغير رأس اللوحة الجانبية لتوفير مساحة تكفي لعرض 9 مستخدمين فعليين على الأقل عند وجودهم.

طريقة الرفع:
- افتح المجلد المستخرج.
- حدد public و package.json والملفين النصيين.
- ارفعها في الصفحة الرئيسية لمستودع rivo-chat عبر Add file > Upload files.
- اضغط Commit changes وانتظر نشر Cloudflare.
